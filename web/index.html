Features

小而完整的更新体验

没有多余的功能，只专注做好一件事：把系统 WebView 更新到最新版本。

识别当前 WebView

通过 WebView.getCurrentWebViewPackage() 读取当前系统 WebView 提供者的包名、版本名与 versionCode。

按系统版本精准匹配

梨在自己的 CDN 上托管了每一个 Webview 版本的安装包，App 会依据 Android 版本号帮用户匹配合适的 Webview。

实时下载进度

下载过程中实时显示已下载 / 总大小 / 百分比与下载速度，进度一目了然。

网络超时智能提示

连接超过 10 秒仍未建立时自动取消下载，并弹窗提示「请连接 VPN 后再试」，不让用户干等。

一键唤起安装器

下载完成后通过 FileProvider 调起系统安装器，并自动引导开启「安装未知应用」权限。

Material You 设计

Material 3 组件 + 动态取色，跟随系统壁纸变化；附带自适应矢量图标（含 Android 13+ 单色主题图标）。

How it works

四步完成更新

整个流程简单透明，无需 Root，无需额外权限。

读取本机信息

获取当前 WebView 包与 versionCode，并从 Build.VERSION.RELEASE 取得 Android 主版本（如 8.1.0 → 8）。

请求版本接口

访问 https://webview-ver.92li.uk/<版本>，获得该系统版本对应的最新 versionCode 与 APK 地址。

比对并下载

若服务器版本更新，确认后开始下载，全程显示进度与速度；连接超时自动中止并提示。

安装更新

通过 FileProvider 唤起系统安装器，完成 WebView 升级，浏览体验即刻焕新。

Build

自行构建

工程结构清晰，本地与 CI 均可一键产出 APK。

# 要求：JDK 17、Android SDK 34
$ git clone https://github.com/lingyicute/WebviewUpdater.git
$ cd WebviewUpdater
# 工程未附带 wrapper，可先生成
$ gradle wrapper --gradle-version 8.7
$ ./gradlew assembleRelease
 
# 产物：app/build/outputs/apk/release/
  • 可使用现有工作流 — fork 本仓库，推送到 main 或手动触发即可产出 apk 构件。
  • 自动发布 Release — 工作流会自动创建带有 nightly 标记的 GitHub Release。
⚠️ Release 构建默认使用 debug 密钥签名，便于直接安装测试。正式分发请在 app/build.gradle 中配置自己的 signingConfig。
